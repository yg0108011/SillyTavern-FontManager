# 字体管理器 Font Manager

SillyTavern（酒馆）第三方字体管理扩展：一键更换全站字体，支持远程 CSS / `@import` 在线字体、本地上传字体文件，并可按语言分组分配字体——英文与数字固定使用 Times New Roman，其余文字使用你上传的字体。

## 功能一览

- **全局字体覆盖**：一键接管酒馆正文、消息气泡、输入框、下拉、按钮、面板等几乎所有界面文字。
- **远程 CSS 注入**：直接粘贴含 `@import url(...)` 的在线字体样式（如字体 CDN / 字由 / 思源字体链接），插件会自动把 `@import` 规则置顶后注入页面。
- **本地上传字体**：支持 `.ttf` / `.otf` / `.woff` / `.woff2`，以 `@font-face` 注册到浏览器本地缓存，离线可用，不上传服务器。
- **按语言分配字体**：
  - 拉丁字母与数字：默认 **Times New Roman**，可在面板中改为其他字体；
  - 中文 / 日文 / 韩文：使用你上传或指定的字体；
  - 其他文字（西里尔、阿拉伯文等）：默认跟随中文，也可单独指定；
  - 代码 / 等宽字体：独立配置，互不影响。
- **正文粗细**：模式选择（保留主题 / normal / lighter / bolder / bold）+ 100–900 数值滑杆微调，实时生效。
- **实时预览**：面板内即时查看拉丁、中文、其他文字、代码四类文字的当前渲染效果。
- **主题适配**：面板沿用酒馆原生控件与配色变量，明暗主题自动适配。

## 安装方法

### 1. 获取文件

- 直接 `git clone` 本仓库，或在仓库页面点 **Code → Download ZIP** 解压；
- 扩展会**自动识别自身所在目录名**，无需手动改文件夹名；`manifest.json`、`index.js`、`style.css`、`settings.html`、`README.md` 需位于同一文件夹内。

### 2. 放入酒馆目录

**当前用户（推荐，无需重启服务）**：`data/<你的用户名>/extensions/<插件文件夹>/`

**全用户（服务端目录）**：`public/scripts/extensions/third-party/<插件文件夹>/`

### 3. 启用扩展

刷新酒馆页面，进入「设置 → 扩展（Extensions）」，在列表中找到 **字体管理器 Font Manager** 并启用。

> 若列表中未出现，请核对上述文件是否位于同一文件夹，然后强制刷新（Ctrl + F5）。

## 使用指南

### 1. 总开关

「启用全局字体覆盖」关闭后，插件会移除全部注入样式，酒馆恢复原有字体，不影响已保存的配置。

### 2. 语言字体分配

| 配置项 | 说明 |
| --- | --- |
| 拉丁字母与数字 | 默认 `Times New Roman`；输入框带候选下拉，可选择系统字体、已上传字体或远程 CSS 中解析出的字体名，也可直接手填。 |
| 中文 / 日文 / 韩文 | 填写你上传字体的 CSS family 名；留空则跟随系统默认中文字体。 |
| 其他文字 | 默认「跟随中文」；取消勾选后可单独为西里尔、阿拉伯文等指定字体。 |
| 覆盖代码字体 | 关闭后代码区域保持酒馆默认等宽字体。 |
| 代码 / 等宽字体 | 下拉候选含 Consolas、JetBrains Mono、Cascadia Code、Menlo 等，可手填。 |
| 正文粗细 | 模式下拉（保留主题 / normal / lighter / bolder / bold）+ 自定义数值滑杆（100–900，步进 50）；选「保留酒馆主题默认」则不主动修改字重。 |

**原理**：CSS 字体栈按**逐字形回退**工作——浏览器渲染每个字符时先尝试栈首字体，缺少该字形才回退到下一项。因此把 Times New Roman 放在最前，英文与数字必然使用它；Times New Roman 不含中日韩字形，会自动落到后面的上传字体上，无需拆分文字或脚本注入。

### 3. 远程字体样式

在文本框中直接粘贴完整 CSS，例如：

```css
@import url("https://fontsapi.zeoseven.com/285/main/result.css");
body {
    font-family: "Noto Serif CJK";
    font-weight: normal;
}
```

- 点击「**应用远程样式**」手动应用；输入修改后约 0.4 秒也会自动应用。
- 插件会自动提取文本中所有 `@import ...;` 规则并置顶（`@import` 必须位于样式表最前才会被浏览器接受，否则会被忽略）。
- 远程 CSS 里顶层的 `body { font-family: ... }` **会被识别为全站主字体**：插件会把它放到全局字体栈的最前，因此全站文字都会优先使用该字体（不再被插件自身的覆盖规则压过）。该字体名同样会出现在语言分配的候选下拉中。
- 远程 CSS 里出现的其他 `font-family` 名称会被自动解析，出现在语言分配的候选下拉中。
- 点击「**填入示例**」可快速填入上面的示例代码。

### 4. 本地字体库

1. 点击「**上传字体**」选择一个或多个字体文件；
2. 在「待导入」区域确认每个字体的 **名称**（CSS family，后续在语言分配中填写此名称）、**字重**、**样式**（正常 / 斜体）；
3. 点击「**确认导入（N）**」完成注册；
4. 已导入字体显示在本地列表中，可单独删除，或使用「清空本地字体」全部移除。

> 字体文件以 Base64 形式存入浏览器 IndexedDB（localforage），不占用扩展设置项；删除扩展时可通过「清理扩展数据」一并清除。

### 5. 实时预览

面板底部预览四块文字：英文数字、中日韩、其他语言、代码，标签行显示当前生效的字体名，修改任意配置后即时刷新。

## 常见问题

**Q：上传字体后界面没有变化？**
- 确认「启用全局字体覆盖」已勾选；
- 确认中文 / 其他文字一栏填写的名称与字体列表中的 family 名完全一致（区分大小写与空格）；
- 个别字重 / 斜体需要同时注册对应字重的字体文件；
- 刷新页面后重试。

**Q：远程 `@import` 或 `body` 字体没生效？**
- 检查链接是否可在浏览器中直接打开；网络 / 代理不通时无法加载；
- 插件会自动把 `@import` 置顶，并会把远程 CSS 顶层 `body` 里的 `font-family` 识别为全站主字体；若你**既写了远程 `body` 字体、又在语言分配栏手动指定了别的字体**，远程字体仍会排在字体栈最前、优先生效；
- 若你在其他主题插件的 CSS 中也写了 `@import`，可能与其冲突，先停用其他主题字体相关插件排查。

**Q：觉得字体太粗 / 太细？**
- 在「正文粗细」里把模式切换为「自定义数值」，用滑杆调到合适的字重（100 最细，900 最粗）；数值越低越细。

**Q：中文显示成方块 / 回退到系统字体？**
- 说明上传字体不含当前字符字形，浏览器会自动回退到字体栈中的下一项；请换用包含该字符集的字体文件。

**Q：想恢复酒馆默认字体？**
- 直接关闭总开关即可；点击「恢复默认显示项」可将语言分配、代码字体、粗细等显示选项还原为出厂默认（本地已上传字体保留）。

**Q：卸载后残留字体？**
- 在扩展管理中删除本扩展并选择清理扩展数据；或手动清空浏览器对应站点的 IndexedDB 存储。
